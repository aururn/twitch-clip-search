# Twitchクリップ検索

配信者を指定せず、Twitchクリップのタイトルをキーワードで検索するChrome拡張です。チャンネルID・ログイン・APIキーの入力は不要です。

Twitchを見ながらサイドパネルで検索できます。公開のクリップ検索データベースをキーワードで調べ、Twitchでタイトルと公開状態を確認して表示します。手元に集めた人気クリップだけを検索する方式から変更しました。

**検索対象は取得できたクリップの一部です。Twitch全体の全件検索には対応していません。** 取得が制限された場合も、それまでの結果は検索できます。

## インストール

Chrome 116以降に対応しています。サーバーの起動やビルドは不要です。

1. このリポジトリをZIPでダウンロードして展開するか、次のコマンドで取得します。

   ```sh
   git clone https://github.com/aururn/twitch-clip-search.git
   ```

2. Chromeで `chrome://extensions` を開きます。
3. **デベロッパーモード**を有効にします。
4. **パッケージ化されていない拡張機能を読み込む**を押し、`manifest.json` がある `extension` フォルダーを選びます。
5. Chromeの拡張機能メニューから **Twitchクリップ検索** を固定し、ツールバーのアイコンを押すとサイドパネルが開きます。

`npm run pack` で作成した拡張機能用ZIPも、展開して `manifest.json` があるフォルダーを選べば読み込めます。

更新後は `chrome://extensions` で拡張機能の再読み込みボタンを押し、サイドパネルを開き直してください。バージョン1.4では検索元の `www.twitch-clips-storage.com` へのアクセス権限が追加されています。ローカルデータを引き継ぐため、読み込み元のフォルダーは移動しないでください。

## 機能

- 配信者を指定せず、クリップのタイトルを検索
- Twitchを見ながらサイドパネルで検索。結果はバックグラウンドの別タブに表示
- 公開の検索データベースから、カテゴリや配信者の上位100件に入らないタイトルも検索
- 複数キーワード・除外キーワード・フレーズ検索
- 全角・半角、英字の大文字・小文字、ひらがな・カタカナの違いを吸収
- 期間・言語・カテゴリによる絞り込み
- 視聴回数順・新しい順・古い順での並べ替え
- クリップのローカル保存と検索結果のCSV出力
- 取得済みの結果と進捗を残したまま停止
- `/` キーで検索欄に移動

## 使い方

キーワードを入力して **検索** を押します。取得済みの結果をすぐに表示し、検索元の該当ページを順に読み込みます。初期設定は「全期間・すべての言語」です。日本語のタイトルでも、クリップの言語が韓国語などに設定されている場合があるため、最初から日本語だけに限定しません。

Twitchで確認できた10件ごとに結果を表示します。1ページ全体の確認が終わるまで待つ必要はありません。直近5分以内に検索して結果がある条件は、再検索時に通信せず表示します。続きを取得する場合は **さらに検索**、取り直す場合は **検索のしくみ → 現在の範囲を最新から取り直す** を使ってください。

バージョン1.3以前からの更新では、この更新で一度だけ言語設定を「すべての言語」に切り替えます。取得データと保存したクリップは残ります。

| 入力例 | 検索対象 |
| --- | --- |
| `爆笑` | 「爆笑」を含むタイトル |
| `爆笑 初見` | 両方のキーワードを含むタイトル |
| `爆笑 -ネタバレ` | 「爆笑」を含み、「ネタバレ」を含まないタイトル |
| `"nice shot"` | 「nice shot」というフレーズを含むタイトル |
| `モンド` / `もんど` | ひらがな・カタカナを区別せず検索。それぞれの表記で検索元も調べます |

長い検索は約45秒で一度止まります。**さらに検索**を押すと続きから再開します。末尾のボタンでは、読み込み済みの次の60件を表示し、表示し終えると検索元の続きへ進みます。取得中はサイドパネルを開いたままにしてください。閉じても、それまでの結果と進捗は残ります。

キーワードを空にした場合は従来のランキング取得を使います。この場合は音声をミュートしたTwitchの一時タブが開くことがあり、拡張が作成したタブだけを終了時に閉じます。

ブックマークボタンでクリップを保存できます。保存したクリップにも検索条件が適用されます。**CSV**で現在の検索結果を書き出せます。

## 検索元と検索範囲

キーワード検索には [Twitchクリップ一覧 in Japan](https://www.twitch-clips-storage.com/app/twitch-clips-jp/) の公開検索を使用します。検索語をこのサービスへ送信します。提携サービスではなく、仕様変更や停止の影響を受けます。

検索元には、直近100日間の1回以上再生されたクリップ、直近3年間の100回以上再生されたクリップ、全期間の500回以上再生されたクリップのデータがあります。「全期間」ではこれらを併せて検索し、重複を除きます。日本語圏を中心とするデータベースのため、未収録の配信者や期間もあります。

検索元は配信者名にも一致するため、その総件数をタイトルの一致数として表示しません。候補のタイトルを絞り込み、Twitchから取得したタイトル・公開状態・日時・言語で確認します。直近1時間に取得したデータは再利用します。削除済みのものや、改題後のタイトルが一致しないものは新規結果に追加しません。

検索元の候補ページは最大24ページ分、IDとタイトルだけを端末に保存し、5分間再利用します。検索語の追加や言語の変更でも同じ候補ページを使える場合は再取得しません。最初の検索で外部サービスの応答を待つ時間は残ります。

**表示件数は、読み込んだデータ内のタイトル一致数です。Twitch全体の総件数ではありません。** 初回の検索に続きがある場合は「さらに検索」で進めます。検索元に未収録のクリップや公開終了したクリップを漏れなく検索できる保証はありません。

かな表記の違いは吸収しますが、ローマ字とかなの自動翻訳は行いません。`mondo` と `モンド` は別の文字列として検索します。

キーワードなしのランキング取得は補助機能です。最大60カテゴリと40配信者を1ラウンドとして最大2ラウンド取得します。各ランキングは上位100件までで、この方式だけでは大量のクリップを取りこぼすため、通常のキーワード検索には使いません。

## プライバシーと権限

- 検索語と期間を `www.twitch-clips-storage.com` の公開検索へ送信します。Twitchのクリップ情報は `gql.twitch.tv` と `www.twitch.tv` から取得します。
- `sidePanel` はサイドパネルの表示、`scripting` はキーワードなしで一覧を取得する際の一時タブの読み取りに使用します。
- 閲覧履歴、アカウントのOAuthトークン、Cookie、パスワード、クライアント検証用トークンは読み取りません。
- 検索元とTwitchへのデータ取得リクエストは `credentials: omit` で送り、検索元には参照元URLも送信しません。一時的なTwitchタブは、使用中のChromeプロファイルの通常のページとして動作します。
- 常駐するコンテンツスクリプトや、すべてのWebサイトへのアクセス権限は使用しません。
- 取得データ、設定、保存したクリップは拡張のIndexedDBに保存します。アプリ独自のバックエンドには送信しません。
- Google検索へのリンクは、クリックした場合にだけ検索語をGoogleへ送ります。
- 拡張機能を削除するとローカルデータも削除されます。必要な結果は先にCSVで書き出してください。

## 開発・動作確認

拡張機能と単体テストに外部ライブラリは不要です。スクリプトの実行にはNode.js 20.3以降を使用します。

```sh
npm test
npm run test:live
npm run test:coverage
npm run test:keywords
npm run test:speed
```

- `npm test`：検索、Unicodeの扱い、URL検証、取得の進捗、配信者の優先順位、重複排除、停止、部分的な失敗、公開ページの読み取りを検証します。
- `npm run test:live`：実際のTwitchデータでカテゴリ取得とタイトル検索を確認します。
- `npm run test:coverage`：同じ言語・期間で5カテゴリのランキングと最大40配信者の追加取得を比較し、クリップ数と検索一致数の増加を表示します。
- `npm run test:keywords`：公開検索元とTwitchの実データで `mondo`、`モンド`、`もんど` のタイトル一致と、存在を確認したクリップが見つかるかを検証します。
- `npm run test:speed`：最初の確認済みバッチが出るまでの時間、1ページの確認時間、同じ候補ページを再利用した場合の時間と通信回数を測ります。通信状況によって値は変わります。

Twitch側の制限によって、ブラウザー外からのリクエストが拒否される場合があります。

ブラウザーテストを実行する場合は、開発用にPlaywrightをインストールします。

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/browser-check.js
node scripts/browser-check.js --live
```

通常のブラウザーテストは固定のテストデータを使います。`--live` を付けると実際の公開検索元とTwitchで `mondo` を検索し、確認済みのクリップが表示されるかを検証します。どちらも専用のChromiumプロファイルにManifest V3拡張を読み込んで実行します。生成したスクリーンショットと配布用ZIPはGitの管理対象外です。

Windowsでは、次のコマンドで拡張機能用ZIPを作成できます。

```sh
npm run pack
```

出力先は `dist/twitch-clip-search-1.4.1.zip` です。

## UI

白い背景と読みやすい文字を使い、検索・絞り込み・取得状況・結果に絞った画面です。サイドパネルには小さなサムネイルとタイトル、配信者名、視聴回数、日付を表示します。スクロール中も検索欄を使えます。

使い方の詳細はヘルプにまとめ、キャッチコピーや装飾用イラストは置いていません。`app.html` を直接開いた場合は、横幅を使った一覧表示になります。
