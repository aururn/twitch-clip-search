# Twitch Clip Search — Minimal Search

The user requested a modern, minimal, readable interface with no promotional copy or unnecessary decoration. The earlier preference for a light theme remains.

- Plain white background, dark text, gray secondary text, and one purple primary action.
- Compact header containing only the app name, search and saved views, and help.
- Search field first, followed by date/language/category controls, one retrieval-status row, and results.
- No hero headline, slogan, introductory paragraph, sample-keyword chips, illustration, colored status panel, fake avatars, or promotional footer.
- Readable clip titles, creator/category details, view counts, and dates. Small bookmark controls remain functional.
- Full usage and coverage details live in the help dialog. Actual retrieval failures remain visible.
- Responsive layout, keyboard focus indicators, and system fonts. No remote fonts, large shadows, or ornamental motion.
- The toolbar action opens Chrome's side panel alongside the current Twitch tab. Compact thumbnail rows keep multiple results visible, with search pinned while scrolling. Opening a clip keeps the watched tab active.
- The initial range is all time and all languages. Keyword searches query a public clip index and verify titles on Twitch, with the provider and its scope described in help. Counts represent loaded title matches. Kana variants are searched together; source totals that also match broadcaster names are never shown as title-result counts.
- Long searches pause after 45 seconds and can resume from stored pages. Ranking collection remains available when no keyword is provided.
